# Translations

Petio ships in English, Spanish, French, Japanese, Vietnamese, and Chinese.

## Requesting a new language

Open a [feature request](https://github.com/jamesng-minhkhoi/petio-mobile/issues/new?template=feature_request.yml)
or start a [Discussions](https://github.com/jamesng-minhkhoi/petio-mobile/discussions)
thread — languages with several interested people get prioritized.

## Helping translate

Translation is a great first contribution:

1. See
   [CONTRIBUTING.md → Translations](https://github.com/jamesng-minhkhoi/petio-mobile/blob/main/CONTRIBUTING.md#translations)
   for the workflow: copy the `en` locale folder, translate, and run the i18n
   parity scripts that verify placeholders and key parity.
2. Placeholders and variables must stay intact in your translations — the
   repo's checks fail the PR otherwise, which keeps translations safe to
   review without speaking the language.

## Site and docs translations

The [landing page](https://www.petiogo.com) is bilingual (English +
Vietnamese). Docs on GitBook start English-only; translated docs are welcome
once the content stabilizes.
